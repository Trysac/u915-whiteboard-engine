# Security Policy

## Supported versions

Only the latest released version of `@trysac/whiteboard-engine` receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report vulnerabilities privately through GitHub's
[security advisory form](https://github.com/Trysac/u915-whiteboard-engine/security/advisories/new).

Include the affected version, a description of the issue and steps to reproduce it. You can expect an
acknowledgement within 7 days and a status update within 30 days.

The practices this repository follows are described in [docs/SECURITY.md](docs/SECURITY.md).
